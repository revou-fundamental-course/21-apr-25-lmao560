# 🌡️ Website Konversi Suhu - Yama

Website ini merupakan aplikasi web sederhana untuk melakukan konversi suhu antara **Celsius** dan **Fahrenheit**. Dibuat menggunakan **HTML, CSS, dan JavaScript** dengan tampilan yang bersih dan fitur yang responsif.

---

## 🔧 Fitur

- ✅ Konversi dari Celsius ke Fahrenheit
- 🔁 Reverse: Konversi dari Fahrenheit ke Celsius
- 🔄 Tombol Reset untuk mengosongkan semua kolom
- ⚠️ Validasi input: tidak boleh kosong & harus angka
- 📜 Penjelasan cara perhitungan disediakan
- 🎨 Tampilan menggunakan CSS eksternal

---

## 🚀 Cara Menggunakan

1. Masukkan angka suhu pada kolom input (Celsius atau Fahrenheit).
2. Klik tombol **Konversi** untuk konversi Celsius → Fahrenheit.
3. Klik tombol **Reverse** untuk konversi Fahrenheit → Celsius.
4. Klik tombol **Reset** untuk menghapus seluruh input dan output.
